We are thrilled to announce **Pace v0.3.0**! 🎉

This release marks a massive milestone for Pace. We've significantly matured the language's backend architecture, optimized memory usage, and introduced highly requested language features like stack-allocated `struct`s, type aliases, and error bubbling. 

> [!WARNING]
> **Breaking Changes Ahead**
> This release includes a few foundational breaking changes, notably to function return syntax and the compilation model. Please read the "Breaking Changes" section carefully before upgrading your projects!

Here is a deep dive into everything new in Pace v0.3.0.

---

## ⚠️ Breaking Changes

### Refined Function Syntax
To enforce a more predictable syntax model, we have **replaced `->` with `:`** for function return types. Function declarations now use `:` uniformly for parameter types, variable types, and return types.

```pace
// ❌ Old Syntax (v0.2.0)
func getUser(id: Int) -> User { ... }

// ✅ New Syntax (v0.3.0)
func getUser(id: Int): User { ... }
```

The `->` operator is now exclusively reserved for **first-class function types** (e.g., `(Int, String) -> Void`).

### Pure AOT Compilation (Goodbye VM!)
We have entirely removed the `compiler/vm` crate. Pace is now a **pure Ahead-Of-Time (AOT) compiled language** running entirely via our Cranelift backend. When you execute `pace run`, it compiles your code into a lightning-fast native executable and seamlessly spawns it, dropping the interpreter overhead entirely.

---

## 🚀 Major Features

### Value Types (`struct`)
You can now define highly efficient, stack-allocated, non-ARC value types using the `struct` keyword!
Structs guarantee pass-by-value semantics and explicitly forbid ARC-managed fields, giving you fine-grained control over your application's memory layout and performance.

### The `?` Error Bubbling Operator
Dealing with `Result<T, E>` is easier than ever. The new postfix `?` operator elegantly unpacks the `Ok` payload or returns early with an `Err` if the expression evaluates to an error.

```pace
func fetchAndProcess(): Result<String, Error> {
    // If fetch fails, the error is immediately returned!
    let data = fetch()?
    return Ok(process(data))
}
```

### Custom Destructors (`deinit`)
Classes can now define a custom `func deinit()`. The compiler dynamically tracks this function and automatically invokes it right before the object's reference count drops to 0 and its memory is freed. Perfect for closing files, network sockets, or releasing resources!

### Type Aliases
You can now define type aliases using the `type` keyword. They are completely transparent to the compiler but drastically improve the readability of your diagnostic messages!

```pace
type StatusCode = Int
type UserId = String
```

### Generic Interfaces
Classes can now formally implement generic interfaces, and the typechecker will properly validate them (e.g. `class MyCollection implements Iterable<T>`). We also lowered `for` loops to natively use `.iter()` and `.next()` under the hood, natively integrating with these interfaces.

---

## 🏗️ Standard Library & Architecture

### Native-Backed Collections
We completely re-architected standard library collections (`List`, `Map`) to be entirely **native-backed**. They now utilize Rust's `Vec` and `HashMap` over a C-ABI bridge. We also introduced a new `Set` standard library wrapper (`stdlib/src/collections/set.pace`)!

### The Math Library
We've added a brand new `math.pace` standard library, complete with essential functions like `sqrt`, `pow`, `abs`, `sin`, and `cos`.

### Massive Compiler Performance Boosts
We completely overhauled the compiler internals to improve performance and drastically reduce memory overhead:
- **String Interning:** AST variables and identifiers now use lightweight `Symbol` handles instead of heavily allocated `String`s.
- **AST Arena Allocation:** We transitioned the AST to use `bumpalo::Bump` for arena allocation, eliminating hundreds of `Box` allocations per file.
- **Rib-Based Scoping:** We re-architected compiler environments to use a flattened "Ribs" pattern, changing variable lookup complexity from `O(N)` to `O(1)`.

---

## 🔒 Safety Enhancements

- **Strict Immutability Enforcement**: We fixed a major typechecker bug where immutability was not fully enforced. Pace now rigorously enforces immutability for variables declared with `let` vs `var`, function arguments, the `self` reference, and `for` loop iterators. Attempting to mutate them will trigger the new `ImmutableAssignment` diagnostic!
- **Generic Enum ARC Fixes**: We fixed a critical bug where generic enum methods were emitting incorrect `pace_retain` calls on stack-allocated generic primitives.
