Pace provides a comprehensive suite of Object-Oriented tools to help you structure large codebases logically. 

## Classes

A `class` acts as a blueprint for an object. Classes in Pace can hold state (properties) and behavior (methods).

```pace
class Rectangle {
    // Properties
    width: int
    height: int
    
    // The Constructor
    fn init(w: int, h: int) {
        self.width = w
        self.height = h
    }
    
    // A Method
    fn area() -> int {
        return self.width * self.height
    }
}
```

To create an instance of a class, call it like a function:

```pace
var rect = Rectangle(10, 20)
println(rect.area()) // Prints: 200
```

### Destructors (`deinit`)

If your class manages external resources (like network sockets or open files), you can define a custom `func deinit()`. Pace's compiler will automatically invoke this function exactly when the object's reference count drops to 0 and its memory is about to be freed.

```pace
class FileHandler {
    fn init() { println("Opened file") }
    fn deinit() { println("Closed file") }
}
```

### Encapsulation and Privacy

By default, all fields and methods in a class are public. You can restrict access to them by prefixing their names with an underscore (`_`). Private members can only be accessed from within the class itself.

```pace
class Account {
    var _balance: int
    
    fn init(initial: int) {
        self._balance = initial
    }
    
    // Public getter
    fn getBalance() -> int {
        return self._balance
    }
    
    // Private helper method
    fn _logTransaction() {
        println("Transaction logged.")
    }
}
```

## Traits

An `trait` defines a strict contract that classes can implement. Traits contain method signatures without actual logic.

```pace
trait Shape {
    fn area() -> int
    fn name() -> string
}
```

You can use the `with` keyword to guarantee a class fulfills the contract. Classes can also implement generic traits (like `implements Iterable<T>`) for advanced polymorphism!

```pace
class Circle with Shape {
    radius: int
    
    fn init(r: int) {
        self.radius = r
    }
    
    fn area() -> int {
        return 3 * self.radius * self.radius // Approximate!
    }
    
    fn name() -> string {
        return "Circle"
    }
}
```

### Polymorphism

Traits allow you to write generic, polymorphic code. Any variable typed as an trait can hold *any* class that implements that trait!

```pace
fn printShapeInfo(shape: Shape) {
    println(shape.name())
    println("Area is:")
    println(shape.area())
}

var c = Circle(5)
printShapeInfo(c) // Works perfectly!
```
