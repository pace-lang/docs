title: Enums & Pattern Matching
description: Define exclusive states and branch logic cleanly using Enums and Pattern Matching.
---

Enums (short for enumerations) allow you to define a type by enumerating its possible variants. In Pace, Enums are incredibly powerful because each variant can optionally store its own data.

## Basic Enums

At their simplest, Enums are just a list of possible states. For example, if you are building a game, you might want to track the state of the player:

```pace
enum PlayerState {
    Idle,
    Walking,
    Running,
    Jumping
}
```

To create a value of this Enum type, you use the Enum name followed by a dot and the variant name:

```pace
state: PlayerState = PlayerState.Jumping
```

## Enums with Data (Algebraic Data Types)

Unlike basic enums in languages like C or Java, Pace's Enums can hold data specific to each variant. This makes them perfect for representing complex states.

For example, a network connection might be disconnected, connecting, or connected (with an active socket ID):

```pace
enum Connection {
    Disconnected,
    Connecting(String), // Stores the URL being connected to
    Connected(Int)      // Stores the active socket ID
}

var activeConnection = Connection.Connected(1024)
var connecting = Connection.Connecting("https://pace-lang.org")
```

## Pattern Matching with `match`

The real power of Enums comes when you combine them with the `match` expression. `match` allows you to execute different code depending on which variant the Enum holds.

The compiler will ensure that your `match` is **exhaustive**—meaning you must handle every possible variant, so you never accidentally forget a case!

```pace
enum Message {
    Quit,
    Move(Int, Int),
    Write(String)
}

func processMessage(msg: Message) {
    match msg {
        Message.Quit => {
            print("Quitting the game...")
        }
        Message.Move(x, y) => {
            print("Moving to coordinates")
        }
        Message.Write(text) => {
            print("Message received: " + text)
        }
    }
}
```

### Match as an Expression

Because `match` is an expression in Pace, it evaluates to a value. This means you can assign the result of a `match` directly to a variable, avoiding clunky `if`/`else` chains.

```pace
var isExitMessage = match msg {
    Message.Quit => true
    _ => false // The '_' is a wildcard that matches anything else
}
```

### Why use Enums?

Enums are the best way to represent data that can be *one thing or another, but never both*. 

For example, instead of having a class with `isConnected`, `socketId`, and `url` fields where some fields are meaningless depending on the state, an Enum ensures that the `socketId` ONLY exists when the state is `CONNECTED`. This prevents entire categories of bugs!

## Generic Enums and Monomorphized Pattern Matching

Pace also supports generic Enums, where variants can hold data of a type specified at instantiation. When pattern matching on a generic Enum, you can explicitly provide the generic type arguments to the variant. This gives the compiler strict guarantees about the monomorphized type it is unpacking.

```pace
var result: Result<Int, String> = fetch_data()

match result {
    Result<Int, String>::Ok(data) => print("Success")
    Result<Int, String>::Err(err) => print("Error")
}
```
