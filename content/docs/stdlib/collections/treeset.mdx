---
title: TreeSet<T>
description: A sorted set storing unique values in ascending order.
---

`TreeSet<T>` stores unique values, maintaining them in sorted order.

## Initialization

```pace
import "pace:collections"

let set = TreeSet<int>()
```

## Modifying the Set

```pace
set.add(50)
set.add(20)
set.add(80)
set.add(50) // Ignored, already exists
```

## Queries

```pace
let size = set.length()
let hasTwenty = set.contains(20)
```
