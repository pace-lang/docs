---
title: Set<T>
description: A collection of unique values backed by a hash set.
---

> [!NOTE]
> `Set<T>` is currently in active development on the Pace standard library roadmap. For native collections supported in Pace v0.3.0, see [`List<T>`](/docs/stdlib/collections/list) and [`Map<K, V>`](/docs/stdlib/collections/map).

`Set<T>` stores unique values without any duplicate elements, backed by an open-addressing hash table.

## Planned API & Syntax

```pace
// Empty set creation
var numbers = Set<int>()

// Adding elements (duplicates are ignored)
numbers.add(10)
numbers.add(20)
numbers.add(10) // Ignored

// Membership queries
if numbers.contains(20) {
    println("Found 20!")
}

// Length and removal
println("Count: ${numbers.len()}")
numbers.remove(10)
numbers.clear()
```
