---
title: Map<K, V>
description: A high-performance open-addressing hash table with SplitMix64 hashing, linear probing, and automated ARC memory safety.
---

`Map<K, V>` is Pace's built-in associative key-value hash map. Keys can be primitives (such as `int`) or `string` values.

`Map<K, V>` is part of the standard prelude—no imports are required.

## Initialization

You can create an empty map with the explicit constructor `Map<K, V>()`, or initialize it with a map literal:

```pace
// Empty map created via constructor
var emptyMap = Map<string, int>()

// Inferred as Map<string, int>
var scores = {
    "Alice": 95,
    "Bob": 88
}

// Map with integer keys
var httpCodes = {
    200: "OK",
    404: "Not Found",
    500: "Internal Server Error"
}
```

## Adding and Updating Entries

You can add or update key-value pairs using subscript assignment `map[key] = value` or through the `.set()` method:

```pace
var scores = {"Alice": 95}

// Subscript assignment (inserts or overwrites)
scores["Bob"] = 88
scores["Charlie"] = 92

// Using .set()
scores.set("Diana", 100)
```

## Reading and Querying Keys

Read values using subscript indexing `map[key]` or `.get(key)`. Check for key existence with `.has()`:

```pace
var scores = {"Alice": 95, "Bob": 88}

// Query key presence
if scores.has("Alice") {
    println("Alice found!")
}

// Read value by key
let aliceScore = scores["Alice"]      // 95
let bobScore = scores.get("Bob")       // 88

// Query entry count
println("Total scores: ${scores.len()}") // 2
```

## Removing Entries

Use `.remove()` to delete an entry by key, or `.clear()` to empty the entire map:

```pace
var cache = {"session_1": 101, "session_2": 102}

// Remove by key (returns true if key existed)
let removed = cache.remove("session_1")

// Clear all entries
cache.clear()
println("Cache size: ${cache.len()}") // 0
```

## Methods Reference

| Method | Signature | Description |
| :--- | :--- | :--- |
| `len()` | `len() -> int` | Returns the number of key-value pairs stored in the map. |
| `has(key)` | `has(key: K) -> bool` | Returns `true` if the specified key exists in the map. |
| `get(key)` | `get(key: K) -> V` | Returns the value associated with `key`. |
| `set(key, value)` | `set(key: K, value: V) -> void` | Inserts or updates the entry for `key` with `value`. |
| `remove(key)` | `remove(key: K) -> bool` | Deletes the entry for `key`. Returns `true` if removed. |
| `clear()` | `clear() -> void` | Removes all entries from the map and resets length to 0. |

## Performance & Memory Architecture

`Map<K, V>` is engineered for high throughput and predictable latency:

1. **Open-Addressing & Linear Probing**: Rather than using linked-list buckets (which cause CPU cache thrashing), entries are stored directly in contiguous table slots. Collision resolution uses linear probing with SplitMix64 hashing for integers and FNV-1a for strings.
2. **64-bit Word Slot Storage**: Keys and values of primitive types (`int`, `float`, `bool`) are stored directly as raw 64-bit words without pointer indirection or heap boxing.
3. **Automated ARC Lifetime Management**: When keys or values are reference types (`string`, classes, or nested collections), the map automatically retains them on insertion and releases them upon removal, replacement, or clearing.
4. **Multi-Language Benchmarks**: In multi-language benchmarks ($N=10,000$ operations), Pace's native map executes in **5.04 ms**, providing nearly 3x the speed of Python and approaching Go and Rust.
