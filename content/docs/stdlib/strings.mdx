title: Strings
description: string manipulation and interpolation in Pace.
---

The `pace:string` module provides robust utilities for string operations. Strings in Pace are immutable, UTF-8 encoded text sequences.

## Interpolation

You can embed variables directly into strings using the `${}` syntax. This is the preferred way to build strings.

```pace
import "pace:string"

let name = "Alice"
let greeting = "Hello, ${name}!"
println(greeting)
```

## `StringUtil` Methods

The `StringUtil` namespace contains all string manipulation functions.

### `substring`
Extract a portion of a string using `StringUtil.substring(s: string, start: int, end: int) -> string`.
```pace
let sub = StringUtil.substring("hello world", 0, 5) // "hello"
```

### `replace`
Replace occurrences of a substring using `StringUtil.replace(s: string, from: string, to: string) -> string`.
```pace
let replaced = StringUtil.replace("hello world", "world", "pace") // "hello pace"
```

### `split`
Split a string into an array of strings based on a delimiter.
```pace
let fruits = StringUtil.split("apple,banana,cherry", ",")
```

### `trim`
Remove leading and trailing whitespace from a string.
```pace
let trimmed = StringUtil.trim("   hello   ") // "hello"
```

### Search Operations
You can use `indexOf` to find the position of a substring, or check prefixes/suffixes.
```pace
let idx = StringUtil.indexOf("hello world", "world") // 6
let starts = StringUtil.startsWith("pace is fast", "pace") // true
```
