---

The `pace:math` module provides common mathematical functions optimized for performance.

## Basic Operations

You can perform comparisons and checks using built-in functions:

```pace
import "pace:math"

let a = 10
let b = 25

println("Max: ${max(a, b)}") // 25
println("Min: ${min(a, b)}") // 10

if isEven(a) {
    println("${a} is even")
}

if isOdd(b) {
    println("${b} is odd")
}
```
