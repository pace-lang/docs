The `pace:http` module empowers Pace applications to make external API calls seamlessly.

## Making a GET Request

You can use the `Http.get(url: String) -> Result<String, String>` function to fetch data from a REST API or web server.

```pace
import "pace:http"

func fetchUserData() -> Result<String, String> {
    let response = Http.get("https://api.github.com/users/pace-lang")?
    return Result<String, String>.Ok(response)
}

let result = fetchUserData()
match result {
    Result<String, String>.Ok(json) => print(json)
    Result<String, String>.Err(e) => print("Network error: " + e)
}
```
