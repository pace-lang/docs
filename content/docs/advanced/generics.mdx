---
title: Generics
description: Write reusable, type-safe, and zero-cost code using type parameters.
---

Generics allow you to write functions, classes, and Enums that can operate on any data type while maintaining strict type safety. This prevents you from having to write the exact same code multiple times for different types.

## True Monomorphization (Zero-Cost Abstractions)

In Pace, generics are **true monomorphizations**. This means that when you use a generic type like `Result<Int, String>`, the compiler doesn't use opaque pointers or box the values under the hood. Instead, it generates a unique, highly optimized machine-code version of the type specifically for `Int` and `String`.

This guarantees **zero-cost abstractions**: your generic code runs just as fast as if you had hand-written specialized versions for each type, and you can safely pass generic structs by-value into C-FFI functions!

## Generic Classes

A classic example of a generic type is a `Box` wrapper. Instead of creating `IntBox` and `StringBox`, you define one generic `Box<T>` where `T` is a placeholder for the type.

```pace
class Box<T> {
    var item: T

    func init(item: T) {
        self.item = item
    }

    func getItem() -> T {
        return self.item
    }
}
```

To use the generic class, you specify the type when you instantiate it:

```pace
let intBox = Box<Int>(10)
print(intBox.getItem())

// intBox.item = "Hello" // Compiler Error: Expected Int, got String
```

## Generic Functions

Functions can also take type parameters.

```pace
func firstElement<T>(arr: [T]): T? {
    if arr.length() == 0 {
        return null
    }
    return arr[0]
}
```

Pace's compiler is smart enough to **infer** the type parameter `T` when you call the function, so you usually don't need to specify it manually:

```pace
let numbers = [1, 2, 3]
let firstNum = firstElement(numbers) // T is inferred as Int!
```

## Generic Enums & Pattern Matching

The standard library extensively uses generic Enums, such as `Option<T>` and `Result<T, E>`. 

Because of monomorphization, when you pattern match on a generic Enum, you can explicitly provide the generic arguments to the variant to ensure absolute type safety:

```pace
var response: Result<Int, String> = fetchData()

match response {
    Result<Int, String>.Ok(data) => print("Data: \{data}")
    Result<Int, String>.Err(err) => print("Error: \{err}")
}
```

### Error Bubbling (`?` operator)
Dealing with `Result<T, E>` is frictionless using the postfix `?` operator. This operator elegantly unpacks the `Ok` payload or returns early with the `Err` if the expression evaluates to an error.

```pace
func fetchAndProcess() -> Result<String, Error> {
    // If fetch fails, the error is immediately returned!
    let data = fetch()?
    return Result<String, Error>.Ok(process(data))
}
```
